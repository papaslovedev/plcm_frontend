# Papas Love Children's Ministry — Frontend

Responsive Next.js + TypeScript landing page inspired by the supplied ministry homepage mockup. Uses Tailwind CSS v4 and lucide-react icons, with custom responsive styling and accessible mobile navigation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Replace the sample Unsplash photography with approved ministry photos and add the supplied transparent logo asset under `public/` when available. Donation links currently open an email request; connect a verified payment provider before accepting payments.
